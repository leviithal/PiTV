# Bidra till PiTV

Börja med `docs/ARKITEKTUR.md` och `docs/TESTPLAN.md`. Fokusera på små, reversibla ändringar. Lämna aldrig API-nycklar, IP-adresser som identifierar användare, cookies eller råa loggar i issues eller pull requests. Tester som mockar `wtype` bevisar inte funktion på en riktig TV. Om möjligt verifiera både Netflix och Disney+ manuellt efter varje ändring.

Koden ska inte användas för att kringgå DRM. Skapa inte issues som ber om delade inloggningar eller rättighetsskyddat material.
