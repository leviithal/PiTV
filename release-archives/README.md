# Originalarkiv

Detta är **originalpaket från utvecklingsstegen**. De är bevarade för versionsspårning och är inte rekommenderade som produktionsinstallationer. Använd `installer/` för nyinstallation. Inga live-tokens eller Chromiums användarprofiler ska ingå. Kör `tools/security-scan.py` och granska alltid själv inför publicering.
