# Lägg till riktiga skärmbilder från projektet

För ett ännu starkare GitHub-repository rekommenderas skärmbilder på:

1. PiTV-startsidan med Netflix och Disney+
2. Android-fjärrkontrollens styrkors/OK/Bakåt
3. Arkitektur-/nätverksöversikten (utan adresser eller nycklar)

**Använd bara bilder från din verkliga installation.** Maskera Android-appens anslutningsuppgifter, API-nyckel, certifikatfingeravtryck och eventuell konto-/profilinformation från streamingtjänsterna. Ladda aldrig upp kopieringsskyddad filmvideo eller privata användaruppgifter.
