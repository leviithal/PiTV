# Installera på ny Raspberry Pi

Den tidigare stegvisa installationsmodellen för V1–V3.2 är **ersatt** av ett sammanhållet V3.3.1 Stable-paket. Följ [INSTALL-V331-STABLE.md](INSTALL-V331-STABLE.md). Historiska installationsfiler finns kvar under `history/` och `patches/` men ska inte köras i kedja på en ny Pi.
