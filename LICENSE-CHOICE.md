# Välj licens innan offentlig publicering

Ingen licens har valts automatiskt för detta användarägda projekt. Du kan själv välja t.ex. **MIT** (permissiv), **Apache-2.0** (inklusive explicita patentvillkor) eller behålla koden utan licens tills vidare. GitHub låter dig lägga till en licens via webbgränssnittet.

Det här repot innehåller originalkod och funktioner beroende av tredjepartsprogramvara (Chromium, Raspberry Pi OS, Gradle, Android SDK). En egen licens ger inte rätt att redistribuera deras komponenter eller Netflix/Disney+-material. Lägg endast upp egen kod och de script/texter du har rätt att publicera.
