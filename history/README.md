# Historisk källkod

`v1.0`–`v2.4` innehåller de **faktiska installatörer och patches** som användes under felsökningen. De är bevarade för spårbarhet, inte för körning på en ny modern installation i följd. Se `src/pi/v2.4` för kodfrysbilden från den installerade V2.4 och `installer/` för rekommenderad nyinstallation.

Originalarkiv är bevarade under `release-archives/`. Där finns även initiala Windows-buildfixar och skrivskyddad systemkontroll. De historiska skripten var inte lika hårdnade som V3 och V2-exponeringsproblemet åtgärdas i den nya installationsvägen.
